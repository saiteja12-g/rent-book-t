# Rent Book (practice copy)

A practice version of Rent Book, a simple rent tracker for iPhone. It opens in Safari with no account or sign-in.

Open it here: https://saiteja12-g.github.io/rent-book-t/

- Everything you enter is kept only on that phone (in the browser's storage). Nothing is sent anywhere, and two phones do not share entries.
- It starts with practice buildings, tenants and payments. Remove them in Settings → Remove sample data.
- Best used from the Home Screen: open the link in Safari, tap Share → Add to Home Screen, then always open it from that icon.

This repository holds only the app's code. It contains no one's real rent records.
